# Consent Report Portal — Vercel + Supabase

نسخه آماده برای GitHub + Vercel + Supabase.

## امکانات فعلی
- ثبت‌نام و ورود
- داشبورد و ساخت پرونده
- لینک اختصاصی با انقضا
- صفحه رضایت
- موقعیت مکانی فقط بعد از اجازه مرورگر
- شماره تلفن فقط در صورت انتخاب رضایت
- ارسال عکس فقط در صورت انتخاب رضایت
- ذخیره اطلاعات در PostgreSQL/Supabase
- آماده برای HTTPS روی Vercel

## راه‌اندازی
1. یک پروژه در Supabase بساز.
2. محتوای `schema.sql` را در SQL Editor اجرا کن.
3. یک Storage Bucket خصوصی با نام `consent-photos` بساز.
4. پروژه را در GitHub قرار بده.
5. Repository را در Vercel Import کن.
6. Environment Variables را از `.env.example` وارد کن.
7. Deploy کن.

## نکات امنیتی مهم قبل از انتشار عمومی
- `SUPABASE_SERVICE_ROLE_KEY` را هرگز داخل GitHub قرار نده.
- برای Production باید CSRF، rate limiting، محدودیت تلاش ورود، مدیریت بهتر session و سیاست حذف/نگهداری داده اضافه شود.
- اطلاعات حساس مثل مکان، شماره و عکس را حداقل زمان ممکن نگهداری کن.
- Bucket عکس خصوصی بماند و برای مشاهده از signed URL کوتاه‌مدت استفاده شود.
- برای OTP واقعی شماره تلفن، یک سرویس SMS یا Phone Auth مثل Supabase Auth باید جداگانه پیکربندی شود؛ این نسخه عمداً OTP جعلی یا ظاهری ندارد.
- این سامانه نباید برای جمع‌آوری مخفیانه اطلاعات یا فریب افراد استفاده شود؛ صفحه رضایت باید شفاف باشد.

## نکته
این نسخه یک پایه قابل Deploy است، نه تأییدیه حقوقی یا محصول امنیتی نهایی.
